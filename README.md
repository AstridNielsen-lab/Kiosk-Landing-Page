# Quiosque Manager

**Sistema completo para gestão de quiosques, bares e estabelecimentos similares.**

## 🔥 Transforme a Gestão do seu Quiosque
O Quiosque Manager é a solução ideal para simplificar o gerenciamento de pedidos, estoque e atendimento no seu estabelecimento. Fácil de usar, seguro e sempre atualizado!

## 🛠 Funcionalidades Principais
- **Cardápio Digital**: Cardápio interativo com imagens e preços em tempo real.
- **Status em Tempo Real**: Acompanhe pedidos em tempo real para clientes e equipe.
- **Relatórios e Análises**: Controle de estoque e relatórios detalhados de vendas.
- **Painel Administrativo**: Gestão completa do seu quiosque em um painel intuitivo.
- **Design Responsivo**: Interface adaptada para dispositivos móveis.
- **Gestão de Dados**: Banco de dados seguro com backups automáticos.

## 💻 Tecnologias Utilizadas
- **Backend**: C# (.NET)
- **Frontend**: React.js
- **Banco de Dados**: SQL Server
- **API**: REST

## 🚀 Começando
### Pré-requisitos
- [Node.js](https://nodejs.org/)
- [Visual Studio](https://visualstudio.microsoft.com/)
- Banco de dados SQL Server instalado e configurado.

### Instalação
1. Clone este repositório:
   ```bash
   git clone https://github.com/seuusuario/quiosque-manager.git
   cd quiosque-manager
   ```
2. Configure o backend:
   - Abra o projeto no Visual Studio e ajuste a string de conexão com o banco de dados no arquivo `appsettings.json`.

3. Configure o frontend:
   - Instale as dependências:
     ```bash
     cd frontend
     npm install
     ```
   - Inicie o servidor:
     ```bash
     npm start
     ```

4. Certifique-se de que o SQL Server esteja ativo e que as tabelas necessárias estejam criadas.

5. Acesse o sistema localmente:
   - Frontend: `http://localhost:3000`
   - Backend: `http://localhost:5000`
